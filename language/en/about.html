About Scripts

Scripts is an open collection of userscripts and userstyles that change how websites look and behave. Userscripts are small JavaScript programs that add or modify features on a page. Userstyles are CSS files that restyle it without any scripting.

Everything here is open source and publicly available for review. Each script and style is checked before it is added, so you can read exactly what you are installing instead of trusting an unknown piece of code.

Getting started

Userscripts need a manager, a browser extension that loads and runs them for you. Tampermonkey and Violentmonkey are the most popular choices, both are free and work in most major browsers. Userstyles are installed with Stylus instead.

Once the extension is installed, pick something from the home page and press Install. Your extension opens a confirmation page where you can review the code before accepting. After that it applies automatically on the websites it was written for.

Installing manually

Open the page of any script or style, press Copy, and paste the code into a new entry in your extension's dashboard. You can turn items off or remove them there whenever you want.

Contributing

You can install, inspect, modify, or share your own. To report a problem, suggest a fix, or add something new, visit the repository and open an issue or pull request.
