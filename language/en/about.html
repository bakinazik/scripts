Welcome to Scripts

Scripts is an open-source collection of userscripts designed to add, modify, or improve functionality on websites. If you're new to userscripts, think of them as small pieces of JavaScript that run directly in your browser and customize how a website works.

Everything here is open source and publicly available for review. Every script is checked before being added, so you can see exactly what you're installing instead of blindly trusting an unknown piece of code.

You can install a script, inspect its source, modify it, or contribute your own. If you'd like to help improve the project, you can visit the repository and submit an issue or pull request.

Getting started

To run a userscript, you first need a userscript manager, a browser extension that loads and runs scripts for you. The most popular options are Tampermonkey and Violentmonkey. Both are free and work in most major browsers, so pick whichever you prefer.

Once a manager is installed, browse the scripts on the home page and press Install on the one you want. Your manager will open a confirmation page where you can review the code before accepting it. After that, the script runs automatically whenever you visit the websites it was written for.

Prefer to do it manually? Open any script's page, press Copy, and paste the code into a new script in your manager's dashboard. You can also turn scripts off or remove them there whenever you want.
